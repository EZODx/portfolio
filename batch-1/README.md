# Batch 1: Programming Fundamentals

This folder contains **50 programming problems** focused on establishing core logic and C++ syntax.

## Overview
The collection covers fundamental concepts, transitioning from basic I/O to algorithmic problem-solving.

## Core Topics
* **Basic I/O:** Standard input/output operations.
* **Math & Geometry:** Implementation of mathematical formulas.
* **Control Flow:** Conditional statements and looping structures.
* **Logic Building:** Developing algorithmic solutions for practical problems.

## Structure
Each problem is organized in a separate folder containing the `.cpp` source file. This batch is dedicated to **Problems** only, serving as the foundation for future projects.
