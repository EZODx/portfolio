# My Sqrt Function

## Methods

### Method 1
Uses the `pow()` function with an exponent of `0.5` and returns a `float` to preserve decimal precision.

### Method 2
Uses the same `pow()` logic but returns an `int`, which truncates the decimal part of the result.

## Note
**Method 1** is more accurate for square root calculations as it handles non-perfect squares.
Both methods demonstrate the mathematical relationship between square roots and powers.
