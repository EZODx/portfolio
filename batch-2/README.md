# Batch 2: Algorithms & Game Logic

This folder contains **50 programming problems** and **2 major projects** focused on intermediate logic, nested structures, and array management in C++.

## Overview
This batch bridges the gap between basic syntax and complex algorithmic thinking, including randomization and interactive console games.

## Core Topics
* **Nested Loops & Patterns:** Generating complex visual and numerical patterns.
* **Number Theory:** Implementing logic for Perfect, Prime, and Palindrome numbers.
* **Array Manipulation:** Comprehensive operations (filling, copying, shuffling, and searching).
* **Randomization:** Building tools for random data generation and security keys.
* **Logic Challenges:** Handling encryption, decryption, and password guessing simulations.
* **Custom Math Library:** Manual implementation of functions like `Sqrt`, `Round`, and `Ceil`.

- **Problems:** 50 folders, each containing a specific algorithmic challenge.
