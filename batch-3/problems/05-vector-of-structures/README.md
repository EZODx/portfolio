# Vector of Structures

## Methods

### Method 1
Uses dynamic input with a custom counter (`EmployeeNum`) to label records during printing. Salary is stored as an `int`.

### Method 2
Uses dynamic input but with a `float` for salary to increase precision. It follows a cleaner print logic without extra counters.

### Method 3
Uses manual initialization (Hardcoded). It bypasses user input to fill the vector directly with predefined records for testing.

## Note
All methods store **Structures** inside a **Vector**. While **Method 1 & 2** are interactive, **Method 3** is the fastest for logic verification.
