# Batch 4: Advanced Matrices, Strings & Bank Project

This batch contains **51 problems** and **2 major projects** covering advanced data manipulation and system logic in C++.

## Core Topics
* **Matrix Operations:** Advanced 2D array logic (Transposing, Multiplication, and Properties).
* **String Manipulation:** Custom functions for Splitting, Trimming, Joining, and Case Conversion.
* **Algorithm Design:** Fibonacci series (Iterative & Recursive) and Pattern recognition.
* **File Database:** Managing client records (Search, Delete, Update) through file streams.

01- Bank System (Phase 1)
02- Bank System (Extension)

Each problem is in a separate folder with its `.cpp` file. This batch focuses on building complex systems and handling data structures effectively.
