# Batch 5: Date Problems & Small Systems

This batch is a structured collection of C++ exercises focused on building strong logical thinking around date handling and time-based calculations, starting from fundamentals and gradually moving into more advanced scenarios.

## Core Topics
* **Date Fundamentals:** Basic rules behind how dates behave in the calendar system.
* **Date Operations:** Manipulating dates through forward and backward movement and comparisons.
* **Period Logic:** Working with time ranges, overlap cases, and duration calculations.
* **Validation & Formatting:** Ensuring correctness of input and controlling output representation.

## Structure
Each task is placed in its own folder with a dedicated `.cpp` file. The batch is designed in a progressive way, where each problem builds on previous concepts to reinforce practical understanding and clean problem decomposition.
