# More Date Problems

Work with calendar utilities like:
- detecting weekdays/weekends
- checking end of week/month/year
- calculating remaining days in week/month/year
- using system date

## Method 1
- Uses date comparison + manual day increment logic
- Includes helper functions for full date operations

## Method 2
- Uses calendar math (days in year/month + day-of-week formulas)
- Avoids increment loops and relies on direct calculations

## Notes
- Both methods solve the same set of date-related problems.
- Method 1 is iterative and simulation-based.
- Method 2 is mathematical and more efficient.
