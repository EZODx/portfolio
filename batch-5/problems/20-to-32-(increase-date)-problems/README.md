# Increase Date Problems

Increase a date by different time units such as days, weeks, months, years, decades, centuries, and millenniums.

## Methods

### Method 1
- Uses helper functions for each increment type.

### Method 2
- Reuses some increments through other functions.

### Method 3
- Uses a mix of helper functions and direct arithmetic.

## Notes
- All methods apply the same date increment rules.
- The difference is mainly in how the increments are composed.
