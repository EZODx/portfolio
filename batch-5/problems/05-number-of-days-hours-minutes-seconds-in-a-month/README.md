# Number Of Days, Hours, Minutes, Seconds In A Month

Calculate the number of days, hours, minutes, and seconds in a given month.

## Methods

### Method 1
- Uses a direct logic-based approach to determine the number of days in a month.

### Method 2
- Uses a structured approach with explicit month definitions and separate leap-year handling.

## Notes
- Both methods produce the same results.
- Method 1 is more compact, while Method 2 is more explicit in structure.
