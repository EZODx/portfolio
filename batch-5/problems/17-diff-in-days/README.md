# Diff In Days

Calculate the difference in days between two dates.

## Methods

### Method 1
- Calculates the difference by incrementing the first date day by day until it matches the second date.

### Method 2
- Calculates the difference by splitting the problem into year parts, using days passed and remaining days in each year.

## Notes
- Both methods assume valid date inputs.
- Both methods produce the same final result using different calculation approaches.
