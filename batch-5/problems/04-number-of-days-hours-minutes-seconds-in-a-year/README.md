# Number Of Days, Hours, Minutes, Seconds In A Year

Calculate the number of days, hours, minutes, and seconds in a given year.

## Methods

### Method 1
- Uses a segmented structure with multiple helper functions.
- Separates logic for different parts of the calculation.

### Method 2
- Uses a chained function approach for calculations.
- More compact and reduces repetition.

## Notes
- Both methods produce the same results.
- Both rely on the same leap year logic.
