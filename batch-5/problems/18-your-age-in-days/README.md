# Your Age In Days

Calculate the age in days based on date of birth and current system date.

## Methods

### Method 1
- Calculates the difference using a reusable function with an optional parameter to include the end day.

### Method 2
- Calculates the age using a dedicated function without extra options.
- Keeps the logic focused on direct day counting.

## Notes
- Both methods depend on system date retrieval for the current date.
- Both produce the same result using the same underlying date-difference logic.
