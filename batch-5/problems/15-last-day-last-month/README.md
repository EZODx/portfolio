# Last Day, Last Month

Check whether a given date is the last day of its month and whether the month is the last month of the year.

## Methods

### Method 1
- Checks conditions directly using function results.
- Performs comparisons inline.

### Method 2
- Stores intermediate results before performing comparisons.
- Separates calculation step from comparison step.

## Notes
- Both methods use the same logic for determining month length and date position.
