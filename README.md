# Portfolio

A structured repository containing programming problems, implementations, and projects organized by batches and topics.

The repository is continuously updated with new problems, projects, languages, and concepts.

---

## Structure

```text
portfolio/
├── batch-1/
├── batch-2/
├── batch-3/
├── ...
└── batch-n/
```

Each batch may contain:

* `problems/`
* `projects/`
* `README.md`

> The structure may vary between batches depending on their content.
